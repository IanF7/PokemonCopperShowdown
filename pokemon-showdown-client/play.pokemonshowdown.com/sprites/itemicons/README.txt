Icons for the custom items go in this folder as PNG files, named by the item
ID (lowercase, no spaces or punctuation), e.g. jinlongite.png. They are shown
in a 24x24 box; the existing ones are 48x48 and get scaled down, which is fine.

Transparent backgrounds look best. A missing file just means no icon is shown;
everything else about the item still works.
